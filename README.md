# Rowing VR flow test

Meta Quest 브라우저용 WebXR 테스트 페이지. 컨트롤러로 노 젓는 동작에 맞춰 VR 영상의 재생 속도가 바뀌는지 확인한다.

- 주소: https://madmachine-x.github.io/rowing-vr/
- 영상은 저장소에 포함하지 않는다. Quest에 저장해 둔 영상을 페이지의 "파일 고르기"로 불러온다.
